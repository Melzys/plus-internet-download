# Plus Internet для Windows

VPN-клиент для Windows с режимами «Весь ПК» и «По приложениям». Можно выбрать сайты и программы, трафик которых пойдёт через VPN.

[![Скачать установщик для Windows](download-windows.png)](https://github.com/Melzys/plus-internet-download/releases/latest/download/Plus-Internet-Setup-x64.exe)

Запустите установщик и откройте Plus Internet. Введите ключ доступа, полученный у владельца. Срок действия появится внизу окна.

[Исходный код sing-box](https://github.com/SagerNet/sing-box) · [Лицензия Wintun](https://www.wintun.net/)
